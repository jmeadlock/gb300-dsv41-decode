# HANDOFF — M1 design: the 6-row DSpark speculative step in our runtime (the headline instrument)

Desk worker (read + write one memo; no code, no GPU). Project: GB300 DSV4.1 Decode, `PROJECT.md`. The headline metric is **ms per decode step at 6 rows** (DSpark speculative decoding, k=5: one verified token position plus five drafts per step), production vLLM does **7.36 ms**, the bar is **≤ 5.0 ms**. Our runtime today decodes **1 row** in **32.2 ms** (`docs/T9B1-RESULT-20261106.md`): one CUDA graph per step, reference arithmetic, DeepGEMM grouped MoE, our MXFP8 GEMV. It has no speculative path at all — DeepSeek's reference `generate.py` is plain greedy. M1 (`docs/M0-PORT-PLAN.md`, `PROJECT.md` ladder) is "DSpark k=5 in the runtime, 6-row step, headline instrument live". Design it.
